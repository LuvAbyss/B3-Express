Saves

Back up your progress before trying a new version or a mod. Backups stay on this PC, in the backups folder beside the launcher.

Restoring replaces the current save. The current one is backed up first, so nothing is lost. Close the game before restoring.

Mods

Mods will replace game files without touching your installed copy. Turning one off goes back to the original files.

⚠
Coming with a later version. The game can't load mods yet. Once it can, they will live as folders in mods, each holding replacement game files, and be turned on and off here.

Help

Something wrong? A bug report with your log helps most.

Report a problem

Makes one zip with the game's log, your options and your PC's graphics card and driver. It holds no game files and no saves. Logs show your folder paths, so look inside before sharing if that matters to you.
